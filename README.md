# Controls AI — Downloads

Public download host for the **Controls AI** desktop application.

The application source code is kept in a private repository. This repository
exists only to host the release installers so the website can serve them to
everyone.

## Latest version

| Platform | File |
|---|---|
| Windows (installer) | `Controls.AI_<version>_x64-setup.exe` |
| Linux (Debian/Ubuntu) | `Controls.AI_<version>_amd64.deb` |
| Linux (portable) | `Controls.AI_<version>_amd64.AppImage` |

Download the newest build from the [Releases](../../releases/latest) page.

## Supported boards

- **Takamul** — STM32F401 · analog inputs, RS-485
- **MK-JL1** — STM32G431 · digital/analog I/O, Ethernet, LoRa
